## ゲームの狙い
- 主人公（魔女の帽子の黒猫）が、下水道に住みつく不定形の魔物を掃除しに行く2Dドットアクション。
- 敵は強く、複数で連携してくるので、基本的には勝てずにやられてしまう。やられるパターンが豊富で、汚されながらもどれだけ抗えるかを試すゲーム。
- 攻撃を受けるたびに主人公が汚れていく。モップで床や敵を押し返す・自分を拭く、など弱い対抗手段がある。
- すぐにゲームオーバーにならず、長く攻撃を受けていられるように調整している。
- ドット絵アニメーションが最も重要。
