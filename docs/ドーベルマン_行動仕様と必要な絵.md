# ペンキドーベルマン：行動仕様と必要な絵（2026-11-13 ユーザー指定、11-14 ヒップドロップ追加・磔の作り直し、11-15 便乗・押し合いっこ・ゲームオーバーの素材とゲームへの組み込み、11-15 ペンキを飲ませる攻撃）

全キャラ共通の制作ルール・見せる前のチェックは `docs/制作ルール（全キャラ共通）.md`。ここはドーベルマンと、ドーベルマンが絡む場面だけ。

立ち絵：`assets/dobe_idle.png`（確定）。すべての絵はこれをベースに作る。フェイントは不要。

## 行動仕様
### 通常時（待ち伏せ）
- **基本は待ち伏せキャラ。直接は追いかけない。** 床の下の一点にじっと潜み（止まっている間はほぼ見えない、動くときだけ床がかすかに盛り上がる）、主人公が真上を通ったら、追われているかどうかに関係なく飛び出して羽交い締め。うっかり踏めば捕まり、捕まりたければ自分から踏みにいける。
- 主人公が他の敵に追われている：前方にいない（追い越された・遠すぎる）ときだけ、逃げる先 140〜200px へいつの間にかワープして待つ。待つ間は動かず、通り道の高さにだけゆっくり寄せる。
- 追われていない：6〜10秒ごとに、主人公の進む先へこっそりワープして待つ。
- ときどき（6〜11秒ごと）その場で顔を見せて潜る（主人公のすぐそばでは出ない）。放したあと潜ってから2.5秒は飛び出さない。
- 羽交い締め中はねっとり揺らす。もがくと更にグラグラ揺らされる。他の敵が来るのを待って連携開始：
  - ワニが来る → ワニが地面に潜る → ドーベルマンが主人公を放り投げる → 空中で磔に捕まる → 「磔に便乗」へ
  - サメが来る → 羽交い締めのまま寛ぐように姿勢を低くする → 「焦らし丸呑み」へ
  - 誰も来ない場合：羽交い締めを維持（放さない）。

### ヒップドロップ（ギャグ寄りの拘束、実装済み）
- 顔見せの時に主人公が110〜560px先にいれば（12〜22秒に1回）：立ち絵からググッと溜めて大ジャンプ → 粘液だまりから抜けて人らしい下半身が見える → 空中で主人公の真上へ寄る → 正面を向いて腕を上げ足を広げる → 尻から急降下 → ベチャァッと着地。
- 当たれば取り込み：立ち上がり（元の顔つきに戻る）→ 振り返って背中を見せる → 蹲踞 → 首だけ振り向く → ふんばる（表情はほぼ変えない、肩・背中の盛り上がりと沈み込み、最大の所で震える）→ 振り向いたまま口を閉じたニヤけ顔で、ピンク×黄マーブルの粘液のとぐろに包んでミチミチと排出 → 出し切って糸が切れ立ち上がる → とぐろを残して本体は溶けて地中へ。
- 立ち上がって振り向くまでは、連打で尻から抜け出せる。
- とぐろの中：連打でネチャネチャ蠢き、溜まると破裂して転んだ状態で出てくる。3秒以上もがいていると、サメがとぐろごと丸呑みにして地中へ（連携）。
- とぐろの中で力尽きた：とどめ演出なし、とぐろの中でときおり蠢き続ける。
- 外れた時：衝撃で近くなら汚れる → 立ち上がって潜る。
- 素材：`assets/dobe_hd_*`（jump/airin/air/todrop/fall/land/stand/turn/squat/look/strain/eject/done/melt）、`assets/mound_idle/wiggle/burst_*`。とぐろは出し切った最後のコマの塊に合わせた大きさ。
- 保留：頭だけ埋まって仁王立ちする場面（主人公入りの絵）、舌なめずりの動き（舌を出すだけの絵になるので保留）。踊って見えた力みは `assets_raw/keep/dobe_strain_dance_*` に保管。

### 磔（ワニ）の作り直し（2026-11-14 ユーザー指定。ドーベルマンの便乗の土台）
- 作る順番：①磔の完成形のワニ → ②磔にされた主人公 → ③捕まる瞬間 → ④ドーベルマンの便乗。
- ワニ：ほぼ柱になりきるが「逞しい胸板に磔にされる」のが大事。腕は真横に広げた十字。頭身は立ち絵基準。口はあまり開けず歯を見せてニヤける、黒目は下。顔が主人公の頭で隠れない。
- **高さは今のゲームと同じ（約140px持ち上げた高さ）に据え置く**（ドーベルマンとの絡みを収めるため）。
- 層（ゲーム内で重ねる）：
  - 奥のワニ：縦長 `assets_raw/wani_cru_tall.png`（256×400。上は決定稿 `wani_cru_key5.png` のピクセル、下に柱を約145px延長）。
  - 猫：もがきループ `assets_raw/cat_cru_struggle/0..7`（128×128、ワニの絵の左上から右へ56px・下へ52px＝帽子の先がワニのあごにちょうど付く高さ。目を閉じた表情、手首・脇・お腹の粘液は焼き込み済みで腕と一緒に動く）。
  - 手前の粘液（固定）：`assets_raw/cru_goo_anchor.png`（足首だけ）。
- ワニのアニメ：ゆっくり呼吸しながらネバネバを垂れ落とすループ（`assets/cru2/breathe_0..7`）。揺れは柱だけを床を支点にしならせ（`cru_bend.gdshader`）、上の群れ（猫・粘液・ドーベルマン）は柱の先に乗ったまま傾く。
- 捕まる瞬間：ワープ感を出さない。柱は床下から一気に生えて上でゆっくり止まる（コード：1-(1-k)^4、頭は波打つ `assets_raw/wani_rise_top/0..7`）。上がり切ったら、ドロドロが盛り上がってグチュグチュと気持ち悪く形成される `assets_raw/wani_form2/0..16`（途中に塊の決めコマ `wani_form_mid.png`。256の窓＝`wani_cru_tall` の上256と同じ位置、下16行は窓と同じ画素）。
- ドーベルマンが生える：柱の横から粘液が盛り上がって塊になり、ドロドロ伸びて抱きつきの姿勢になる `assets_raw/dobe_emerge/0..15`。
- 猫の反応：ドーベルマンが生えたら軽く怯える `assets_raw/cat_cru_startle/0..8`（目を開けて左下を見る）→ 抵抗失敗後の擦りつけ中はイヤイヤするループ `cat_refuse`（目をつぶって首を振る、口ほんの少し開け・涙少し、足は動かさない）。
- ゲームオーバー（磔）：ワニだけ＝胸に取り込む `assets_raw/go_wani_absorb/0..8`（256の窓）。ドーベルマンがいる＝抱きしめたまま柱へ押し込んで一緒に溶け込む `assets_raw/go_dobe_press/0..8`。どちらも丸い膨らみの後、さらにドップンと沈む `go_wani_sink/0..6` → 中でアバウトにグチャグチャ揺らすループ `go_wani_churn`（帽子は外に見せない・胸の高さで止める・ぶつぶつにしない）。
- ゲームへの組み込み：素材は `assets/cru2/`、描画は `enemy.gd` の `_cru2_update`。ドーベルマン側（`doberman.gd`）は状態だけ進めて自分の絵は隠す。確認は smoke の `solo=cru`。

### 磔に便乗
- 柱から粘液ごと生えて、猫に背中をこちらに向けて抱きつく。下半身は柱にくっついたまま動かさない。層の位置は `CRU2_DOBE`（ワニの左上から x-35, y+49）。
- 見た目の区別（輪郭を濃くする等）は作らない。色はワニに合わせる（`tools/hue_fix.py` / `palette_lock.py`）。生成後の穴は `tools/fill_small_holes.py`。
- **普段の顔：目元が見えない角度（後ろからの横顔）。** 口は閉じて口角だけそれとなく上げる。
- 押し合いっこ（もがいている間だけ動く。入力が止まると抱きしめの姿勢で止まる）：抱きしめ⇄のけぞりを止めずにぐいぐい続けるループ `assets/cru2/dobe_push_0..7`（9fps 一定、溜め・止まりなし）。
  - のけぞり：押し返されたふり。腰から上を少し反らせ、頭を後ろへ倒して閉じ目の薄ら笑い（記号の弧の目・「＜」の口はなし）。**前腕と手は柱をつかんだまま固定、腕を伸ばさない。** 猫から離れすぎない。
  - 猫 `cat_push_0..7`：手首の粘液から手を抜き、顔は右（逆）へ背ける。両手はずっとドーベルマンの肩に付けたまま、弱々しく押す（肘を引いて手を見せない）。ドーベルマンと同じコマ番号で1周1押し。
- 抵抗に失敗した後：がっちり抱きついたまま、次の2つを3.5秒ずつ交互に。
  - 擦りつけ `dobe_rub_0..7`：体を擦りつけて汚す（背中向きの専用の絵は未作成、今は抱きしめの決めコマから作ったループ）。猫は `cat_refuse`。
  - **ペンキを飲ませる**（11-15）：ドーベルマンは鼻先をすぼめて猫の口に重ねる（後ろから見ているので口は向こう側に隠れて見えない。口・歯・目は描かない）。2匹とも顔は完全に隠れる。頭と首だけ0〜4ドットゆっくり上下するゴクゴク、鼻先の付け根から細い粘液の糸が垂れる。体・腕・下半身は動かさない。素材 `assets/cru2/dobe_drink_0..7`（決めコマ `assets_raw/dobe_drink_key5.png`）。猫 `cat_drink_0..7`：抱き寄せられたまま手は動かさず見せない、喉だけゴクゴク、体が微かにビクビク震える（生成のループ＋コードで不規則に1ドットのビクッ）。音は `slurp`（無理やり流し込むゴクッ・グチュッ）。
- 抱きしめられても、もがけば（遅めに）磔から抜けられる。

### 焦らし丸呑み
- 羽交い締め → 正面にサメが浮上してゆっくり口を開ける → 振りほどけなければ2匹まとめて丸呑み → 口を閉じてゴクン → 2匹を抱えたまま床に沈んで引きずり込む。

### 2対1に追撃（3対1）
- 地中で引き回されているところに、やたら綺麗なフォームで巨体がドップンと飛び込んで参戦。
- 腹の中の小窓（ドーベルマンがいる時だけ400×240に広げて2倍）・抜けた後の地面：寝かせた向きの挟み込み（下にワニ、上からドーベルマンがのしかかり、間に主人公が埋もれる）。
  - ループ：締め上げ `assets/embrace_0..7` と押しつぶし `assets/embrace_crush_0..7`（3周:2周、1周1.25秒）。キーは `assets_raw/embrace_key4.png`。
- 出入り：3対1から抜けると、挟まれた姿のまま地面から溶け出るように湧き出る（`trio_rise_*`）。挟み込み中は6〜10秒ごとに半々で、挟んだまま溶けて沈み、地中の3対1へ戻る（`trio_drag_*`）。主人公だけが外に出る場面は無い。
- HP0：寝そべった姿勢とデザインのまま、ドーベルマンがワニに腕を回して抱き寄せ → 押しつけて密着 → 主人公がドプンと完全に沈む（`trio_absorb_*`、約3秒）→ 寝そべったまま抱き潰し続ける（`trio_absorbed_*`、終わらない）。
- 3対1で負けたら（腹の中）、サメはワニと一緒にドーベルマンも吐き出す。

### 効果音
- 全体的に濡れてグチョグチョ・ネチャネチャした音（`tools/gen_sfx.py`、ElevenLabs、各3種）。作り直すときは `sfx/<名前>/` を消してから `gen_sfx.yml`。

### 他の敵との関係
- サメ：遊撃型。主人公の左右200px強を並走・回り込み → 一瞬溜めて先読み位置へ突っ込み、すれ違いざまに呑む → 外れたら走り抜けて離れる。遠ければ大ジャンプ。連携（ワニの抱きつき・羽交い締め・とぐろ）は決めに来る。
