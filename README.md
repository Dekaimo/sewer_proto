# 下水道掃除 試作（Godot 4.3+）

仕組みを確認するための試作です。絵は仮の四角形です。

## 起動
1. Godot 4.3以降をインストールし、`project.godot` を開いて F5 を押す。

## 操作
- 移動：← → / A D　　ジャンプ：↑ / W / Space
- モップ攻撃：Z（敵を押し返す＋前方の床のペンキを消す）
- 自分を拭く：X 長押し（その場で止まり、汚れが少しずつ落ちる）
- 捕まったとき：← → を交互に連打して脱出（Z/Xでも少し）
- R：リトライ
- **マウスでも操作可**：左クリック＝モップ（カーソル方向）／左長押し＝カーソルへ歩く／右長押し＝自分を拭く／ホイール上・中クリック＝ジャンプ／捕まったらマウスを左右に振る

## 入っている仕組み
- **汚れマスク＋シェーダー**（`player.gd` / `dirt.gdshader`）：当たった場所がピンク・黄色のマーブルで塗られる。汚れ率が上がるほど足が遅くなり、被ダメージも増える（最大1.5倍）
- **HPは汚れとは別**：0でゲームオーバー（被弾8／捕まり中じわじわ／連携5）
- **攻撃権トークン**（`main.gd`）：同時に攻撃する敵は1体だけ
- **2対1の連携**（`enemy.gd`）：1体が掴むと、もう1体が反対側に回り込んで追加で汚す（抵抗ゲージも削る）
- **床のペンキ**：踏むと足が遅くなり、足元から汚れていく。モップで消せる

## 素材の差し替え
`player.gd` の `_ready()` で作っている仮の絵を、PixelLabの素材（AnimatedSprite2D）に置き換えます。汚れマスクは同じサイズの画像で持つので、シェーダーはそのまま使えます。
